Loan types are the named lending categories staff pick when they start an application, each built on one of four security bases.

A loan type pairs a name your team recognises, such as "Staff Auto", with a fixed **security basis**. The security basis decides how the loan is priced and risk-rated, which form sections the Credit Officer fills in, and which loan agreement is used. You can add as many named types as you like on the four bases.

**Required permission:** **Manage loan types**, held by the Administrator and the Credit Manager.

Open **Administration → Loan Types**. Rest the pointer on a type's name to see its code, security basis, and number of products.

<Note>
  This page is about setting up loan types. For what each type means when capturing a loan, see [Loan types](/omnia/los/loans/loan-types).
</Note>

## The four security bases

Every workspace starts with one loan type on each basis.

| Security basis | Starting code | Starting name | Used for |
|---|---|---|---|
| Unsecured | `UNS` | Unsecured | Personal loans with no collateral |
| Cash secured | `CASH` | Cash secured | Loans secured by the member's shares or savings |
| Motor vehicle | `AUTO` | Motor vehicle | Loans secured by a vehicle |
| Real estate | `MORT` | Real estate | Loans secured by property |

## What a loan type contains

| Field | What it is |
|---|---|
| **Code** | A short, unique identifier such as `CSA` or `DIASPORA`. 2 to 20 characters: uppercase letters, numbers, and dashes |
| **Name** | What staff see when they pick a type. 2 to 80 characters |
| **Security basis** | Unsecured, Cash secured, Motor vehicle, or Real estate. Set once, at creation |
| **Sort order** | A number from `0` to `9999`. Lower numbers appear first |
| **Description** | An optional note, up to 500 characters |

<Warning>
  The security basis cannot be changed after you create the type. Changing it on a type already in use would send its loans down the wrong pricing, forms, and documents. If you need a different basis, create a new loan type.
</Warning>

## Creating a loan type

<Steps>
  <Step title="Open Loan Types">
    The header shows the total and active counts, for example "8 loan types · 6 active". Use the **All**, **Active**, and **Archived** tabs, the search box, and the **All security bases** filter to narrow the list.
  </Step>
  <Step title="Click New loan type">
    The form opens.
  </Step>
  <Step title="Enter a code and name">
    The code must be unique in your workspace.
  </Step>
  <Step title="Choose the security basis">
    Pick **Unsecured**, **Cash secured**, **Motor vehicle**, or **Real estate**. Choose carefully: it cannot change later.
  </Step>
  <Step title="Set the sort order and description">
    Enter a sort order from `0` to `9999` and an optional description.
  </Step>
  <Step title="Click Create loan type">
    The type is created and the change is recorded in the audit trail.
  </Step>
</Steps>

## Editing a loan type

Open the type and click **Edit**. Change the code, name, sort order, or description, then click **Save changes**. The security basis shows read-only.

The edit page also lists the products built on this type, with each product's application count and rate source. If you can manage loan products, you can create and archive this type's products right there.

## Documents attached to a loan type

The edit page has a **Required documents** panel for the legal documents this type's loans carry.

- **Always required** lists, read-only, the documents the security basis always needs, such as the credit consent and disbursement sheet on every loan, and the security documents for vehicle and property loans. Documents that depend on the loan, such as a guarantee for each guarantor, are added automatically when they apply.
- **Add document** makes another form available for this type. Pick the **Document** and the stage it **Blocks at**: Securities or Disbursement. A guarantee cannot be added here, because it is always one per guarantor.

An added document is optional. On each loan it shows a **Require for this loan** checkbox and blocks nothing until a staff member ticks it. Once ticked, it holds the loan at its stage until it is signed. Adding and removing documents needs **Manage document templates**. See [Legal documents](/omnia/los/legal-documents/overview#optional-documents-per-loan-type).

## Archiving and restoring a loan type

Archive a type you no longer offer. Staff can no longer pick it, and every loan and product that used it is left as it is. Loan types are never deleted.

- **To archive:** find the type and click **Archive**.
- **To restore:** open the **Archived** tab, find the type, and click **Restore**.

Both are recorded in the audit trail.
