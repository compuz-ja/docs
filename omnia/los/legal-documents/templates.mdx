A document template is your credit union's own version of a form, registered once and mapped to the loan data that fills it, so the system can prepare that exact form for every loan.

Adding a new form is a setting you change yourself. No software release, no waiting.

<Note>
  Find templates under **Administration → Document Templates**. Changing them needs the **Manage document templates** permission, which only the **Administrator** and **Credit Manager** hold. Templates sit alongside products, rates, and the fee schedule as configuration.
</Note>

## Three ways to fill a form

How a template is filled depends on what your source form looks like. You choose the **Engine** when you register it.

<CardGroup cols={1}>
  <Card title="PDF form fields (AcroForm)" icon="file-check">
    Your form is a fillable PDF with named fields. Each value goes into its named field. Use this when your legal team already has an interactive PDF.
  </Card>
  <Card title="PDF coordinate overlay" icon="file-text">
    Your form is a flat PDF, such as a scan or a pre-printed form with no fillable fields. Each value is printed at the spot on the page you mark. Use this for a form you cannot alter.
  </Card>
  <Card title="Structured layout (no PDF)" icon="list">
    There is no source PDF. The system lays out the whole document: headings, fields, repeating tables, and running totals. The Loan Disbursement Sheet and the Declaration of Purpose are built this way.
  </Card>
</CardGroup>

## Register a template

<Steps>
  <Step title="Open the register form">
    On **Document Templates**, click **Register a template**. Give it a short identifier (the slug) and a name, and choose the **Document kind** it fulfils, for example Personal Credit Consent or Guarantee & Indemnity.
  </Step>
  <Step title="Pick the engine and upload the source">
    Choose the **Engine**. For either PDF engine, upload the **Source PDF**. Every upload is checked to be a real PDF, stripped of any active content, and virus-scanned before it is stored. A file that is not a PDF, is over 20 MB, is password-protected, or is damaged is rejected with the reason. A structured layout needs no source.
  </Step>
  <Step title="Map the fields">
    In **Field mapping**, say which loan value fills which blank. You can type the mapping as JSON, or, on a PDF template, use the **Visual editor** to click each spot on the page and pick the value that lands there. A mapping can only use the loan data allowed for that form. Anything else is rejected with "The field mapping is invalid (check the sources against the allowed fields)."
  </Step>
  <Step title="Preview it">
    Click **Preview** on the row to fill the template with sample data and check every value lands in the right place. Preview as often as you like. A preview never uses a real member: the Loan Disbursement Sheet preview, for example, prints a made-up account number.
  </Step>
  <Step title="Activate it">
    Click **Activate**. The template becomes the live version of that form and staff can prepare it on loans straight away. Any earlier live version of the same form is archived and marked as replaced. See [Legal documents](/omnia/los/legal-documents/overview) for how staff use it.
  </Step>
</Steps>

## Draft, active, archived

Each template shows its state as a badge.

| State | What it means |
|---|---|
| **Draft** | Being built. You can edit the mapping, use the visual editor, and preview. It does not appear on any loan. |
| **Active** | Live. Loans are prepared from this version. |
| **Archived** | Retired. It no longer prepares on new work. |

<Frame caption="Templates are grouped by form. Each group says where that form is required, and each row carries its version and state.">
  <img src="/images/omnia/los/admin/document-templates.png" alt="The Document Templates page listing registered templates grouped by form, each with a version number and its state" />
</Frame>

Each row shows the template's name, version (**v1**, **v2**, and so on), identifier, engine, and page count. Rows are grouped by form, and each group says where the form is required, for example **Always required on every loan** or **Always required on Auto loans**, followed by any loan types that offer it as an optional document.

A draft row offers **Edit mapping**, **Visual editor** (PDF templates), and **Activate**. An active row offers **Archive**. An archived row offers **Restore as draft**, which copies it into a new draft with the next version number and re-checks its mapping, so a mapping that is no longer allowed is flagged instead of restored broken.

<Note>
  Every loan needs the **Personal Credit Consent** and the **Loan Disbursement Sheet**, so the last active template of either cannot be archived. Activate a replacement version instead.
</Note>

Only a draft can be edited. Once activated, a version is fixed. To change a live form, register and activate a **new version**. Earlier versions stay on file, so the exact template behind any signed document can always be reproduced.

<Warning>
  Activating a new version never changes documents already prepared or signed. A member who signed against v2 has a v2 document for good. New documents use whichever version is active when someone clicks **Prepare**.
</Warning>

## What a template is allowed to print

Each form can only use a fixed set of loan data: the names, amounts, dates, and parties that belong on it, and no more. The mapping is checked when you save it, when you restore it, and every time a document is prepared.

The member's core banking account number is allowed on one form only, the **Loan Disbursement Sheet**, and even there only masked to its last five digits. No template can print the full number. See [Loan Disbursement Sheet](/omnia/los/legal-documents/disbursement-sheet#the-member-account-stays-masked).

That limit is what lets you build your own forms without any risk of printing the wrong data.

## The forms you can register

| Document kind | Usual engine | Notes |
|---|---|---|
| Personal Credit Consent | Structured layout | The borrower's, plus one per guarantor. |
| Declaration of Purpose | Structured layout | Needed when the net to member is below the declaration threshold. The purposes must total the gross loan. |
| Guarantee & Indemnity | PDF form fields or overlay | One per guarantor. |
| NSIPP Security Agreement | PDF form fields or overlay | Auto loans. |
| Loan Disbursement Sheet | Structured layout | Builds the double-entry table and totals, and prints with your logo, legal name, footer, and prepared-by stamp. |
| Mortgage Deed | PDF form fields or overlay | Mortgage loans. |
| Insurance Assignment | PDF form fields or overlay | Mortgage loans. |
| Additional form | Any | As many of your own forms as you need, such as an authority to release a vehicle title or a salary deduction order. Each has its own active version. Filled on request from the **Additional forms** card. Never holds a loan up. |

When your credit union needs a new form, register it, map it, preview it, and activate it. It is ready on the next loan that needs it.

Every registration, activation, archive, and replacement is recorded in the audit trail with who did it and when.
