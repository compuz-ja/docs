## What it answers

What does the Financial Investigations Division need behind a suspicious transaction report?

| | |
|---|---|
| Report key | `reg-fid-str-support` |
| Edition | Comply, tier 1 |
| Owner | Compliance Officer |
| Capability | `reports.aml.run` |
| Delivery | On demand |
| Regulator | FID |
| Modules | `DW04`, `DW07` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **Alert reference** | text | Yes | — |

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
