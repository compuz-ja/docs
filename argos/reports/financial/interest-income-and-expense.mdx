## What it answers

What is the loan book earning, and what are deposits costing?

| | |
|---|---|
| Report key | `fin-interest-income` |
| Edition | Comply, tier 1 |
| Owner | Finance Officer |
| Capability | `reports.financial.run` |
| Frequency | Monthly |
| Delivery | On demand |
| Modules | `DW05` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **From month** | month | Yes | `PERIOD_START_MONTH` |
| **To month** | month | Yes | `LAST_CLOSE_MONTH` |

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `month_label` | text | Month |
| `interest_income` | currency | Interest income |
| `interest_expense` | currency | Interest expense |
| `net_interest` | currency | Net interest |
| `withholding_tax` | currency | Withholding tax |
| `loan_accounts` | integer | Loan accounts |
| `deposit_accounts` | integer | Deposit accounts |

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
