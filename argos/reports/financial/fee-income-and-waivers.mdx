## What it answers

What did fees earn, and what was given away?

| | |
|---|---|
| Report key | `fin-fee-income` |
| Edition | Comply, tier 1 |
| Owner | Finance Officer |
| Capability | `reports.financial.run` |
| Frequency | Monthly |
| Delivery | On demand |
| Modules | `DW05`, `DW09` |

## Parameters

| Parameter | Type | Required | Default |

| **From** | date | Yes | `PERIOD_START` |
| **To** | date | Yes | `LAST_CLOSE` |

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `fee_category` | text | Category |
| `fee_name` | text | Fee |
| `charge_count` | integer | Charges |
| `fee_income` | currency | Fee income |
| `gct_collected` | currency | GCT |
| `waived_value` | currency | Waived |
| `waiver_rate` | percent | Waiver rate |

<Note>
  The waived column is the point of this report. Fee income net of waivers is a different number from fee income, and only one of them is a policy question.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it.
