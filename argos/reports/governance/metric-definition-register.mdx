## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `metric_key` | text | Metric |
| `display_name` | text | Name |
| `domain` | text | Domain |
| `definition` | text | Definition |
| `unit` | text | Unit |
| `owner_role` | text | Owner |
| `regulatory_ref` | text | Regulatory reference |
| `version` | integer | Version |
| `status` | text | Status |
| `approved_by` | text | Approved by |

<Note>
  One owner-approved definition per metric, versioned. Two people quoting different delinquency ratios is a definition problem, and this is where it is settled.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
