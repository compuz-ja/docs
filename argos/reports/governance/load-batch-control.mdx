## What it answers

Did every extract arrive, complete?

| | |
|---|---|
| Report key | `gov-load-batches` |
| Edition | Comply, tier 1 |
| Owner | Data Steward |
| Capability | `platform.ops.view` |
| Delivery | On demand |
| Modules | `DW01`, `DW02`, `DW17` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **From** | date | Yes | `PERIOD_MONTH_START` |
| **To** | date | Yes | `LAST_CLOSE` |
| **Source system** | select | No | `ALL` |

**Source system** offers **Every source**, **Meridian core system**, **Halcyon core system**, **Digital banking**, **Card processor and switch**, **ATM network**, **AML screening**.

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `business_date` | date | Business date |
| `source_system` | text | Source |
| `feed_name` | text | Feed |
| `records_declared` | integer | Declared |
| `records_loaded` | integer | Loaded |
| `records_rejected` | integer | Rejected |
| `control_total_declared` | currency | Control total |
| `control_total_loaded` | currency | Loaded total |
| `hash_match` | text | Hash |
| `status` | text | Status |
| `duration_sec` | number | Duration (s) |

<Note>
  The control total the source declared against the control total the warehouse computed. These agreeing is the first thing that has to be true; nothing downstream means anything if they do not.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
