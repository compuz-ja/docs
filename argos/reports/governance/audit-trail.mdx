## What it answers

Who did what, when, and from where?

| | |
|---|---|
| Report key | `gov-audit-trail` |
| Edition | Comply, tier 1 |
| Owner | Compliance Officer |
| Capability | `audit.view` |
| Delivery | On demand |
| Modules | `DW16` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **From** | date | Yes | `TODAY_MINUS_30` |
| **To** | date | Yes | `TODAY` |
| **Event type** | select | No | `ALL` |
| **Outcome** | select | No | `ALL` |

**Outcome** offers **Any outcome**, **Success**, **Denied**, **Failure**.

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `occurred_at` | datetime | When |
| `actor_email` | text | Actor |
| `event_type` | text | Event |
| `object_type` | text | Object type |
| `object_id` | text | Object |
| `outcome` | text | Outcome |
| `ip` | text | IP |
| `row_hash` | text | Chain hash |

<Note>
  The chain is hashed per workspace. A gap or an edited row breaks the chain and is visible, which is the property that makes this admissible as evidence.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
