## What it answers

What does ALCO need to see about liquidity and rate risk?

| | |
|---|---|
| Report key | `mgmt-alco` |
| Edition | Anticipate, tier 3 |
| Owner | Executive |
| Capability | `reports.run` |
| Frequency | Monthly, alco calendar |
| Delivery | Batch |
| Modules | `DW08` |

<Warning>
  This report sits at **Anticipate**. It is a projection, not a record of what happened.
</Warning>

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `business_date` | date | Date |
| `cash_on_hand` | currency | Cash |
| `bank_balances` | currency | Bank balances |
| `investments` | currency | Investments |
| `liquid_assets` | currency | Liquid assets |
| `member_deposits` | currency | Member deposits |
| `liquidity_ratio_pct` | percent | Liquidity ratio |
| `net_cash_flow` | currency | Net cash flow |
| `concentration_pct` | percent | Top-10 concentration |

<Warning>
  This report contains estimates produced from the institution's own data. Estimates are not forecasts of certain outcomes and no result is warranted by CompuZign. Read them with the confidence and coverage stated in the output, and against the institution's own judgement, before relying on them.
</Warning>
