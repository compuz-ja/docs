## What it answers

Which way are the headline ratios moving?

| | |
|---|---|
| Report key | `mgmt-kpi-trend` |
| Edition | Understand, tier 2 |
| Owner | Executive |
| Capability | `reports.run` |
| Delivery | On demand |
| Modules | `DW08` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **From month** | month | Yes | `PERIOD_START_MONTH` |
| **To month** | month | Yes | `LAST_CLOSE_MONTH` |

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `month_label` | text | Month |
| `members_total` | integer | Members |
| `total_assets` | currency | Total assets |
| `total_deposits` | currency | Deposits |
| `gross_loans` | currency | Gross loans |
| `delinquency_pct` | percent | Delinquency |
| `capital_adequacy_pct` | percent | Capital adequacy |
| `liquidity_ratio_pct` | percent | Liquidity |
| `cost_to_income_pct` | percent | Cost to income |
| `net_surplus` | currency | Net surplus |

<Note>
  A single reading is a number. A direction of travel is information, which is why this report exists alongside the board pack.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
