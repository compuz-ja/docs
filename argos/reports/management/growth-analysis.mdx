## What it answers

What grew, where, and by how much?

| | |
|---|---|
| Report key | `mgmt-growth` |
| Edition | Understand, tier 2 |
| Owner | Executive |
| Capability | `reports.run` |
| Delivery | On demand |
| Modules | `DW08`, `DW10` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **Period** | month | Yes | `LAST_CLOSE_MONTH` |
| **Analyse by** | select | No | `family` |

**Analyse by** offers **Product family**, **Branch**.

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `grouping` | text | Group |
| `accounts_open` | integer | Accounts |
| `accounts_opened` | integer | Opened |
| `accounts_closed` | integer | Closed |
| `members_holding` | integer | Members |
| `prior_month_balance` | currency | Prior balance |
| `closing_balance` | currency | Closing balance |
| `balance_growth` | currency | Growth |
| `growth_pct` | percent | Growth % |

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
