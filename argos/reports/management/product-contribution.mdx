## What it answers

Which products actually contribute?

| | |
|---|---|

| Parameter | Type | Required | Default |

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `product_family` | text | Product family |
| `accounts` | integer | Accounts |
| `average_balance` | currency | Average balance |
| `interest_accrued` | currency | Interest |
| `fees_earned` | currency | Fees |
| `total_contribution` | currency | Contribution |
| `yield_pct` | percent | Yield on balance |
| `transaction_count` | integer | Transactions |

<Note>
  Interest and fee income against interest expense, on the average balance each was earned on. A product with a large book and a thin margin can contribute less than a small one.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
