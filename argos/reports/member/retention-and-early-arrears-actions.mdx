## What it answers

Who is about to leave or slip into arrears, and what can be done about it?

| | |
|---|---|
| Report key | `dec-retention-actions` |
| Edition | Decide, tier 4 |
| Owner | Executive |
| Capability | `decision.view` |
| Frequency | Monthly |
| Delivery | On demand |
| Modules | `DW10`, `DW08` |

<Warning>
  This report sits at **Decide**. It is a recommendation. Nothing here is a decision until a named officer records one.
</Warning>

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **Period** | month | Yes | `LAST_CLOSE_MONTH` |
| **Worklist size** | number | No | `20` |
| **Action type** | select | No | `all` |

**Action type** offers **All**, **Retention**, **Early arrears**.

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `recommendation_id` | text | Reference |
| `subject_ref` | text | Member |
| `recommended_action` | text | Recommended action |
| `why` | text | Why |
| `value_at_stake` | currency | Value at stake |
| `action_cost` | currency | Cost |
| `expected_value` | currency | Expected value |
| `value_per_dollar` | number | Per dollar |
| `confidence` | percent | Confidence |

<Note>
  Every row needs a named officer before it can leave the open state. The platform raises the recommendation; a person decides it.
</Note>

<Warning>
  This report recommends actions on the evidence stated beside each one. It is analysis, not advice, and no outcome is warranted by CompuZign. Every recommendation requires a decision by an authorised officer of the institution before any action is taken, and that decision is recorded with the evidence it rested on. Nothing here is acted on automatically.
</Warning>

## Exports and evidence

The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
