## What it answers

How much of the book is in arrears, and how far behind?

| | |
|---|---|
| Report key | `risk-delinquency-aging` |
| Edition | Understand, tier 2 |
| Owner | Risk Analyst |
| Capability | `reports.risk.run` |
| Frequency | Monthly |
| Delivery | On demand |
| Modules | `DW06`, `DW09` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **Period** | month | Yes | `LAST_CLOSE_MONTH` |
| **Group by** | select | No | `branch` |

**Group by** offers **Branch**, **Product**.

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `grouping` | text | Group |
| `loans_total` | integer | Loans |
| `gross_loans` | currency | Gross loans |
| `current_value` | currency | Current |
| `d1_30` | currency | 1-30 |
| `d31_90` | currency | 31-90 |
| `d91_plus` | currency | 91+ |
| `delinquency_pct` | percent | Delinquency |
| `npl_pct` | percent | NPL |

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
