## What it answers

Do the risk ratings actually predict arrears?

| | |
|---|---|
| Report key | `risk-member-rating` |
| Edition | Anticipate, tier 3 |
| Owner | Risk Analyst |
| Capability | `reports.risk.run` |
| Delivery | On demand |
| Modules | `DW06`, `DW10` |

<Warning>
  This report sits at **Anticipate**. It is a projection, not a record of what happened.
</Warning>

| Parameter | Type | Required | Default |

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `risk_rating` | text | Risk rating |
| `members` | integer | Members |
| `pct_of_members` | percent | % of members |
| `total_deposits` | currency | Deposits |
| `total_borrowings` | currency | Borrowings |
| `delinquent_members` | integer | Delinquent |
| `delinquency_rate` | percent | Delinquency rate |
| `pep_count` | integer | PEP |

<Note>
  If members rated low risk carry the same arrears as members rated high risk, the rating model is not working. That comparison is the report.
</Note>

<Warning>
  This report contains estimates produced from the institution's own data. Estimates are not forecasts of certain outcomes and no result is warranted by CompuZign. Read them with the confidence and coverage stated in the output, and against the institution's own judgement, before relying on them.
</Warning>
