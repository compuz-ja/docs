## What it answers

How exposed is the institution to its largest borrowers?

| | |
|---|---|
| Report key | `risk-concentration` |
| Edition | Comply, tier 1 |
| Owner | Risk Analyst |
| Capability | `reports.risk.run` |
| Delivery | On demand |
| Modules | `DW06`, `DW08` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **As at** | date | Yes | `LAST_CLOSE` |
| **Show top** | number | No | `25` |

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `rank` | integer | # |
| `member_number` | text | Member |
| `member_name` | text | Name |
| `branch_name` | text | Branch |
| `loan_count` | integer | Loans |
| `total_exposure` | currency | Exposure |
| `collateral_value` | currency | Collateral |
| `net_exposure` | currency | Net exposure |
| `pct_of_book` | percent | % of book |
| `pct_of_capital` | percent | % of capital |
| `worst_dpd` | integer | Worst DPD |

<Note>
  Each exposure is shown against institutional capital, which is what the prudential limit is expressed in. A large loan is only a concentration relative to capital.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
