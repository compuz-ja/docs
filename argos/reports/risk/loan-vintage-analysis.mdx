## What it answers

Is recent lending performing worse than older lending at the same age?

| | |
|---|---|
| Report key | `risk-vintage` |
| Edition | Understand, tier 2 |
| Owner | Risk Analyst |
| Capability | `reports.risk.run` |
| Delivery | On demand |
| Modules | `DW06`, `DW10` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **Product family** | select | No | `ALL` |

**Product family** offers **All lending**, **Loans**, **Lines of credit**.

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `cohort` | text | Disbursement cohort |
| `months_on_book` | integer | Months on book |
| `loans_originated` | integer | Loans |
| `original_value` | currency | Originated |
| `outstanding_value` | currency | Outstanding |
| `loans_delinquent` | integer | Delinquent |
| `delinquency_rate` | percent | Delinquency rate |

<Note>
  Comparing cohorts at the same months on book is what removes the effect of the book simply being younger. Reading raw delinquency by disbursement month does not.
</Note>
