## What it answers

What happened next to the loans that were in each bucket?

| | |
|---|---|
| Report key | `risk-rollrate` |
| Edition | Understand, tier 2 |
| Owner | Risk Analyst |
| Capability | `reports.risk.run` |
| Frequency | Monthly |
| Delivery | On demand |
| Modules | `DW06` |

## Parameters

| Parameter | Type | Required | Default |
|---|---|---|---|
| **Period** | month | Yes | `LAST_CLOSE_MONTH` |

## Reading a row

| Column | Type | Meaning |
|---|---|---|
| `from_bucket` | text | From |
| `to_bucket` | text | To |
| `loan_count` | integer | Loans |
| `balance_moved` | currency | Balance |
| `roll_pct` | percent | Roll rate |

<Note>
  Roll rates out of the early buckets are the leading indicator. By the time the late buckets move, the outcome is already set.
</Note>

## Exports and evidence

Every run writes a row to the audit trail with the run identifier shown above, the parameters used, the row count and who ran it. The **CSV**, **XLSX**, **PDF** and **JSON** buttons export exactly the rows on screen, so an export and its audit entry always agree. **Definition** opens the report definition this page describes.
