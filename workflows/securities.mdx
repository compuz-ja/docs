The Securities team reviews collateral documentation for approved secured loans before funds are released. Your job is to verify that every required document is present, properly executed, and satisfies the credit union's perfection requirements. Once all security requirements are met, the loan moves to Disbursement automatically.

<Note>
Unsecured loans skip the Securities stage entirely — they route directly from **APPROVED** to **DISBURSEMENT**. You will only see secured loan types (Auto, Mortgage, and Cash-Secured) in your queue.
</Note>

## What you need

You must have the **Securities Reviewer** role, which includes the `securities.review` capability. Credit Officers can also access Securities detail pages to upload documents, but they cannot approve or reject security requests — that requires `securities.review`.

## Which loans come to Securities

| Loan type | Routes through Securities? |
|---|---|
| Auto | Yes |
| Mortgage | Yes |
| Cash-Secured | Yes |
| Unsecured | No — goes directly to Disbursement |

## Reviewing a loan

<Steps>
  <Step title="Open the Securities queue">
    Go to **Admin → Securities**. The queue shows approved loans awaiting collateral review. Use the **All / My queue / Unassigned** tabs to filter to your assigned files or unclaimed work.
  </Step>
  <Step title="Open the application">
    Click a row to open the Securities detail page. You'll see the full application summary, the risk assessment, and the collateral details submitted by the Credit Officer.
  </Step>
  <Step title="Review collateral and documents">
    Check the **Collateral Summary** card for the collateral type, estimated value, and any documents already attached. Cross-reference what's required for this loan type against what's been provided.
  </Step>
  <Step title="Take action">
    - If all documents are in order and the collateral is correctly perfected, proceed — the loan will route to Disbursement once all security requests are resolved (see below).
    - If anything is missing or incomplete, raise a Security Request.
  </Step>
</Steps>

## Raising a Security Request

A Security Request is a formal sub-workflow that notifies the Credit Officer of a specific document requirement. You can have multiple open requests on the same loan at the same time.

<Steps>
  <Step title="Click Raise Security Request">
    On the Securities detail page, find the **Side Actions** panel and click **Raise Security Request**.
  </Step>
  <Step title="Specify what is needed">
    Describe the document required — for example: *Vehicle title*, *Insurance binder*, *Property valuation*, or *Survey diagram*. Be precise; the Credit Officer sees your description and uses it to locate or obtain the document.
  </Step>
  <Step title="Submit the request">
    Submit the form. The Credit Officer is notified by email immediately. The loan moves to **SECURITIES_ISSUE** status to signal that action is required.
  </Step>
  <Step title="Officer uploads the document">
    The Credit Officer uploads the requested document against the member's file and marks the request as submitted. You receive a notification to review.
  </Step>
  <Step title="Review the uploaded documents">
    Return to the Securities detail page. The request card now shows **SUBMITTED** status. Review the uploaded document against the requirement.

    - **Approve** — the document satisfies the requirement. Click **Approve** and add any notes. The request moves to **RESOLVED**.
    - **Reject** — the document is malformed, incomplete, or doesn't match what was asked for. Click **Reject**, enter a reason (required), and the Officer is notified to resubmit.
  </Step>
  <Step title="Loan routes to Disbursement">
    Once every Security Request on the loan is **RESOLVED**, the loan automatically routes to **DISBURSEMENT** and the Disbursement team is notified. You can optionally use the **Route Disbursement to** picker (shown when you resolve the last request) to hand the file directly to a specific Disbursement Officer.
  </Step>
</Steps>

## Security Request states

| Status | Meaning |
|---|---|
| PENDING | Request raised; Credit Officer has been notified and must upload documents |
| SUBMITTED | Officer has uploaded documents; awaiting Securities review |
| RESOLVED | Documents approved; this request is cleared |
| REJECTED | Documents rejected; Officer must resubmit |

## SECURITIES_ISSUE state

When one or more Security Requests are open (PENDING or SUBMITTED), the loan sits in **SECURITIES_ISSUE** status. This status signals to the Credit Officer that action is required on their end. The loan automatically returns to **SECURITIES** status when the Officer submits the outstanding documents.

A loan can cycle between SECURITIES and SECURITIES_ISSUE multiple times if successive rounds of requests are needed.

## What happens when all requests are rejected

If every Security Request on a loan is rejected with no resolved requests on record, the file cannot proceed from Securities. In this situation, iLoan automatically sends the loan back to **ADJUDICATION** so the Adjudicator can re-evaluate — whether to restructure the collateral plan, request new information from the officer, or decline the loan entirely. Both the Adjudicators and the originating Credit Officer are notified.

## After Securities — the Disbursement path

Once all requests are resolved, iLoan notifies the Disbursement team automatically. Depending on your credit union's configuration, the loan may also return to Securities for a final check after disbursement occurs — your Tenant Administrator controls this setting. If the final check is enabled, you'll see the loan re-appear in the Securities queue at the **DISBURSED** stage before it is filed.

<Tip>
There must be zero open Security Requests (PENDING or SUBMITTED) for the loan to proceed to Disbursement. Resolve or reject all outstanding requests before expecting the loan to advance.
</Tip>

## Securities Dashboard

The **Securities Dashboard** at **Admin → Securities → Dashboard** shows a summary of active and completed requests, request turnaround times, and queue volume by loan type. Use it to track workload and identify loans that have been sitting in SECURITIES_ISSUE for an extended period.
